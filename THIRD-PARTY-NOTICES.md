# Third-Party Notices

## Adobe/DEC X11 Bitmap Fonts (Helvetica)

This project includes generated bitmap glyph data derived from the following source files:

- `helvR10.bdf`
- `helvB10.bdf`

Upstream source repository:

- https://gitlab.freedesktop.org/xorg/font/adobe-75dpi

The generated data is used for the built-in `Proportional12` and `Proportional12Bold` fonts.
